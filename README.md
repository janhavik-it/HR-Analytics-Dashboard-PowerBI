# HR-Analytics-Dashboard-PowerBI

## Project Overview
An interactive HR Analytics Dashboard
developed using Power BI to analyze
employee data and workforce trends.

## Key Insights
- Total Employee Count
- Employee Attrition Rate
- Average Salary and Age
- Attrition by Gender and Education
- Job Role Analysis
- Salary Slab Analysis

## Tools Used
- Power BI
- Power Query
- Data Visualization
- DAX
